## `salary`

Look up salary benchmark data


- **Usage:** `salary [FLAGS] [company]`

### Arguments
- **`[company]`** — Company name to search for

### Flags
- **`--city`** — Filter by city name
- **`--json`** — Output as JSON
- **`--list-all`** — List all companies
- **`--validate`** — Validate salary_data.json and print a report
