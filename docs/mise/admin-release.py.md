## `admin:release`

Automate semantic version tag creation (version/X.Y.Z) and release publishing


- **Usage:** `admin:release [-p --push] [version]`
- **Aliases:** `release`

### Arguments
- **`[version]`** — Semantic version to release (e.g. 1.0.0). If omitted, prompts interactively.

### Flags
- **`-p --push`** — Push the commit and created version tag to origin
