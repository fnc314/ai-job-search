## `tracker:event`

Append a timeline event


- **Usage:** `tracker:event [FLAGS] <id>`

### Arguments
- **`<id>`** — Application ID

### Flags
- **`--type <type>`** — Event type (e.g. event:interview)
- **`--date <date>`** — ISO date the event happened
- **`--note <note>`** — Event note
- **`--json <json>`** — Extra fields as JSON
- **`--dry-run`** — Preview without writing
