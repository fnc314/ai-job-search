## `tracker:edit`

Modify fields of an existing application record


- **Usage:** `tracker:edit [FLAGS] [id]`

### Arguments
- **`[id]`** — Application ID or UUID to edit

### Flags
- **`--company <company>`** — New company name
- **`--role <role>`** — New role title
- **`--status <status>`** — New funnel status
- **`--channel <channel>`** — Application channel
- **`--job-url <job_url>`** — Job posting URL
- **`--note <note>`** — Optional context note for the event
