## `search:rank`

Evaluate a job posting against the candidate profile (single-job fit score)


- **Usage:** `search:rank [--json] <url_or_jd>`
- **Aliases:** `rank`

### Arguments
- **`<url_or_jd>`** — Job URL, local file path, or job description text (required)

### Flags
- **`--json`** — Output as JSON instead of markdown
