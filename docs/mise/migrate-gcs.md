## `migrate-gcs`

Upload local artifacts to GCS and backfill Firestore (set TRACKER_ALLOW_WRITES=1)


- **Usage:** `migrate-gcs [FLAGS]`

### Flags
- **`--dry-run`** — Show tree view without uploading
- **`--company`** — Only process artifacts for this company (case-insensitive)
- **`--documents`** — Path to documents/applications/ directory
