## `ui:web:server`

Serve and preview the web dashboard on localhost


- **Usage:** `ui:web:server [FLAGS]`
- **Aliases:** `dashboard`

### Flags
- **`-p --port <port>`** — Port to listen on (default: 8000)
- **`-b --host <host>`** — Host address to bind to (default: 127.0.0.1)
- **`-r --regenerate`** — Regenerate dashboard HTML from tracker before starting
- **`--no-browser`** — Do not automatically open the browser
