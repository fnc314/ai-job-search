## `tracker:score`

Record a recalculated fit rating


- **Usage:** `tracker:score [FLAGS] <id>`

### Arguments
- **`<id>`** — Application ID

### Flags
- **`--fit <fit>`** — Integer 0-100
- **`--date <date>`** — ISO date the score was decided
- **`--note <note>`** — What changed in the evaluation
- **`--dry-run`** — Preview without writing
