## `tracker:edit`

Modify fields of an existing application record


- **Usage:** `tracker:edit [FLAGS] [id]`

### Arguments
- **`[id]`** — Application ID or UUID to edit

### Flags
- **`--app-id <app_id>`** — Application ID or UUID to edit
- **`-i --interactive`** — Interactively select record and edit fields
- **`--dry-run`** — Preview changes without writing
- **`--job-url <job_url>`** — Job posting URL
- **`--job-application-url <job_application_url>`** — Job application portal URL
- **`--company <company>`** — Company name
- **`--role <role>`** — Role title
- **`--status <status>`** — Target status
- **`--date <date>`** — Application date
- **`--contact-person <contact_person>`** — Contact person
- **`--contact-email <contact_email>`** — Contact email
- **`--fit-rating <fit_rating>`** — Fit rating
- **`--note <note>`** — Audit note
