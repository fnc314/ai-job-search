## `tracker:list`

List applications


- **Usage:** `tracker:list [FLAGS]`

### Flags
- **`--status <status>`** — Filter by status
- **`--open`** — Only open applications
- **`--tag <tag>`** — Filter by an exact tag value
- **`--limit <limit>`** — Max results to return
- **`--json`** — Output as JSON
- **`--tui`** — Launch interactive TUI with these filters
