## `salary:lookup`

Look up salary benchmark data


- **Usage:** `salary:lookup [FLAGS] [company]`
- **Aliases:** `salary`

### Arguments
- **`[company]`** — Company name to search for

### Flags
- **`--city <city>`** — Filter by city name
- **`--json`** — Output as JSON
- **`--list-all`** — List all companies
- **`--validate`** — Validate salary_data.json and print a report, then exit
