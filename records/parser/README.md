# Records Parser: Contract Parsers & Domain Converters

Multiplatform parsing utilities, timestamp conversions, status normalizers, and remote persistence projection logic.

## Overview

- **`DocumentIdGenerator`**: Canonical slug generation for company and application IDs.
- **`TimestampParser`**: Robust multi-format ISO-8601 and Firestore timestamp parsing.
- **`StatusNormalizer`**: Validates pipeline state transitions and assigns visual category priority.
